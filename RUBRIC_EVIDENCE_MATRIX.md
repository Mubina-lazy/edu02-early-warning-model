## Essential passing requirements

- [x] The project includes a model trained by the student - XGBoost, trained on
      the 2013 presentations (`src/train_experiments.py`). No external AI
      service or hosted API is used as the model.
- [x] The final model is evaluated on unseen data - the 2014J cohort, scored
      once, after all decisions were frozen (`reports/final_evaluation.md`).
- [x] A working end-to-end demo exists - `demo.ipynb`, verified in a fresh
      Colab runtime (`docs/REPRODUCTION_TEST.md`).
- [x] Reproduction instructions are clear - README sections 10-12; the demo
      needs four packages and no dataset download.
- [ ] The student will attend the defence and answer questions.

## Cross-cutting evidence

| Claim | How to verify it yourself |
|---|---|
| No leakage | `src/config.py` lists the banned columns; `src/features.py` filters every aggregation to `date <= cutoff_day` and asserts no banned column survives |
| The split is honest | `reports/split_summary.csv` - sizes, at-risk rates, and the student overlap between eras, stated rather than hidden |
| The test set was used once | `reports/experiments_results.md` records that selection happened on validation; `docs/EXPERIMENT_LOG.md` marks the test column "not used for tuning" |
| The numbers are not hand-written | Every figure in `reports/project_report.html` is generated by `src/build_report_data.py` from the model's own predictions |
| The pipeline is deterministic | Repeated runs of the same name in `reports/mlflow_runs.csv` reproduce identical metrics |
| The documented example still works | `tests/test_inference.py::test_documented_example_still_reproduces` |
